# Effekt-Option-3

Dritter effekt-spezifischer Parameter (0–255).

## Effekt-spezifische Bedeutung

| Effekt | Bedeutung |
|---|---|
| **Rainbow (ID 2)** | phase / start hue offset |
| **Juggle (ID 5)** | hue offset / start hue |
| **Cylon (ID 7)** | FadeAmount (1-255 - Trail fade speed |
| **GarageDoor (ID 9)** | breathing speed override (0 = default) |
| **Noise (ID 21)** | hue offset |
| **Palette (ID 22)** | index spacing (0 => auto-fit) |
| **Lightning (ID 23)** | hue for colored lightning (only if feature1=1) |
| **Gradient (ID 24)** | saturation (0 => 255) |
