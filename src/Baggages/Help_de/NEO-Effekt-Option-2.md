# Effekt-Option-2

Zweiter effekt-spezifischer Parameter (0–255).

## Effekt-spezifische Bedeutung

| Effekt | Bedeutung |
|---|---|
| **Rainbow (ID 2)** | saturation (0 => 255) |
| **Juggle (ID 5)** | fade speed (0=default, 1..50) higher = faster fade |
| **Cylon (ID 7)** | EyeSize (1-10 - Size of the eye |
| **GarageDoor (ID 9)** | runway group size (0 = default) |
| **Fire (ID 10)** | sparking probability (0=default, else 0..255 mapped to ~50..200) |
| **Theater Chase (ID 11)** | dot size (1..5, 0 => default 1) |
| **Sinelon (ID 13)** | dot size (0 => 1) |
| **Breathing (ID 16)** | curve shaping (0 = linear, 255 = more exponential) |
| **Comet (ID 19)** | tail length (0 = default) |
| **Noise (ID 21)** | saturation (0 => 255) |
| **Palette (ID 22)** | blend (0=nearest, 1=linear) |
| **Lightning (ID 23)** | decay speed (0 => default) |
| **Gradient (ID 24)** | end hue (0-255) |
