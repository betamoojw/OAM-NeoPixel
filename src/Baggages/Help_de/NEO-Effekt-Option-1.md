# Effekt-Option-1

Erster effekt-spezifischer Parameter (0–255).

## Effekt-spezifische Bedeutung

| Effekt | Bedeutung |
|---|---|
| **Wipe (ID 1)** | direction (0..5) (WipeDirection) |
| **Rainbow (ID 2)** | hue spacing / wavelength (0 => auto) |
| **Confetti (ID 4)** | Saturation (0-255 - Color saturation |
| **Juggle (ID 5)** | number of dots (0=default, 1..16) |
| **BPM (ID 6)** | Hue (0-255 - Starting hue offset |
| **Cylon (ID 7)** | Hue (0-255 - Eye color |
| **RGBW_Test (ID 8)** | phase duration override in ms steps (0 => 5000ms, else option1*100ms) |
| **GarageDoor (ID 9)** | arrow size / trail length (0 = default) |
| **Fire (ID 10)** | cooling control (0=default, else 0..255 mapped to ~20..100) |
| **Theater Chase (ID 11)** | spacing (1..10, 0 => default 3) |
| **Sinelon (ID 13)** | fade rate control (0 => default) |
| **Breathing (ID 16)** | minimum brightness floor |
| **Comet (ID 19)** | tail fade rate (0 = default) |
| **Noise (ID 21)** | spatial scale (0 => default) |
| **Palette (ID 22)** | palette id (0..N-1) |
| **Lightning (ID 23)** | strike width (0 => auto) |
| **Gradient (ID 24)** | start hue (0-255) |
